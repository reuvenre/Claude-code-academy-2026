Agent view הוא מסך אחד לכל סשני הרקע של Claude Code. מריצים `claude agents`, מקלידים משימה ולוחצים `Enter`, וכל משימה רצה כסשן נפרד. כל שורה מראה אם הסשן עובד, מחכה לך או סיים. `Space` פותח הצצה ותשובה מהירה, ו-`Enter` נכנס לשיחה המלאה.

## למה זה חשוב
כשיש כמה משימות עצמאיות, לא צריך לשבת מול כל אחת. שולחים תיקון באג, סקירת pull request וחקירת בדיקה לא יציבה כשלוש שורות, ממשיכים לעבוד, וחוזרים רק כששורה מראה שהיא צריכה אותך או שיש תוצאה. כל סשן רקע הוא שיחה מלאה של Claude Code שממשיכה לרוץ בלי טרמינל פתוח.

<Callout type="note">
Agent view נמצא ב-research preview. הממשק וקיצורי המקלדת עשויים להשתנות.
</Callout>

להשוואה בין agent view,‏ subagents,‏ agent teams ו-worktrees, ראה [סקירת הסוכנים במקביל](/pro/agents-overview).

## איך פותחים agent view ושולחים משימה?

<StepList>

1. מה-shell, בתיקיית הפרויקט:
   <CommandBlock>claude agents</CommandBlock>
   אם עוד לא אישרת את דיאלוג ה-workspace trust לתיקייה, הוא יופיע קודם, כמו ב-`claude`.
2. מקלידים תיאור משימה ולוחצים `Enter`. סשן רקע חדש מתחיל ומופיע כשורה. כל prompt שמקלידים כאן פותח סשן **חדש**, לא הודעת המשך לסשן הקודם.
3. בוחרים שורה עם החיצים ולוחצים `Space` כדי לפתוח את פאנל ההצצה (peek). כותבים תשובה ולוחצים `Enter` כדי לשלוח אותה בלי לצאת מ-agent view.
4. לוחצים `Enter` או `→` על שורה כדי להיכנס (attach) לשיחה המלאה. `←` על prompt ריק מחזיר לטבלה.
5. `Esc` יוצא ל-shell. הסשנים ממשיכים לרוץ ויופיעו שוב בפעם הבאה שתפתח את agent view.

</StepList>

הסשן החדש משתמש במודל שמוצג בכותרת של agent view. מחליפים אותו עם `/model` בשורת השליחה. על בחירת מודלים ראה [model-config](https://code.claude.com/docs/en/model-config).

כברירת מחדל הרשימה מציגה את כל סשני הרקע שלך מכל הפרויקטים. כדי לראות רק פרויקט אחד:

```bash
claude agents --cwd ~/projects/my-app
```

## מה אומר הסטטוס של כל שורה?
כל שורה מתחילה באייקון שהצבע שלו מראה את מצב הסשן:

| מצב | איך נראה | מה זה אומר |
| --- | --- | --- |
| Working | מונפש | Claude מריץ כלים או כותב תשובה |
| Needs input | צהוב | מחכה למשהו שרק אתה יכול לתת: תשובה לשאלה או החלטת הרשאה |
| Idle | מעומעם | אין לו מה לעשות, ומוכן ל-prompt הבא |
| Completed | ירוק | המשימה הסתיימה בהצלחה |
| Failed | אדום | המשימה הסתיימה בשגיאה |
| Stopped | אפור | הסשן נעצר, למשל עם `Ctrl+X` |

הרשימה מקובצת כך שמה שצריך אותך למעלה: `Ready for review` ו-`Needs input` מעל `Working` ו-`Completed`. סשן עובר ל-`Ready for review` כשיש לו pull request פתוח, ואז מופיעה בקצה השורה תווית כמו `#1234`. כשהמספר הופך לירוק, הבדיקות עברו ואין review שחוסם.

השורה כוללת גם סיכום של משפט אחד: מה הסשן עושה, מה הוא שואל או מה יצא ממנו. מודל קטן כותב את הסיכום בסוף כל תור, והבקשה מחויבת כמו שאר השימוש שלך. בזמן שהסשן עובד, השורה מתעדכנת גם מהפלט של הסשן עצמו, בלי בקשה נוספת למודל.

## איך עונים לסשן בלי לפתוח את כל השיחה?
לוחצים `Space` על השורה. פאנל ההצצה מראה את מה שחשוב עכשיו, ולא את כל התמליל:

- **סשן שמחכה לך:** השאלה המדויקת, מעל שדה התשובה. אם יש אפשרויות מוגדרות, הן מופיעות ברשימה ממוספרת ובוחרים במקש מספר.
- **סשן שסיים:** התוצאה.
- **סשן שעובד:** משפט הסטטוס המלא.

`↑` ו-`↓` עוברים לסשן הסמוך בלי לסגור את הפאנל. בקשת הרשאה מופיעה כטקסט בלי אפשרויות ממוספרות. עונים עליה בכתיבה, או נכנסים לסשן ועונים ב-prompt הרגיל.

## איך נכנסים לסשן ויוצאים ממנו?
`Enter` או `→` על שורה מחליפים את agent view בסשן האינטראקטיבי המלא. Claude מפרסם סיכום קצר של מה שקרה בזמן שלא היית, וכל הפקודות והקיצורים עובדים כרגיל.

כדי לחזור לטבלה לוחצים `←` על prompt ריק או מריצים `/exit`. יציאה אף פעם לא עוצרת סשן רקע. כדי לסיים סשן מתוכו מריצים `/stop`.

## איך מעבירים סשן קיים לרקע?
יש שלוש דרכים, לפי מה שאתה רוצה שיקרה לטרמינל שלך:

| מה עושים | מה קורה |
| --- | --- |
| `←` על prompt ריק | הסשן עובר לרקע ו-agent view נפתח עם השורה שלו מסומנת |
| `/background` (או `/bg`) | השיחה עוברת לרקע והטרמינל מתפנה |
| `/fork` | עותק של השיחה עובר לרקע, ואתה ממשיך לעבוד במקור |

אפשר להוסיף הוראה אחרונה, והיא נשלחת לפני המעבר:

```text
/bg run the test suite and fix any failures
```

אחרי `/fork` שתי השיחות עצמאיות: מה שהעותק עושה לא נכנס לשיחה המקורית מעצמו. אם [הודעות בין סשנים](/pro/cross-session) מופעלות, כל אחד מהם יכול לשלוח הודעה מפורשת לשני.

אפשר גם להשתמש ב-`claude agents` כנקודת הכניסה הראשית במקום `claude`: שולחים כל משימה מ-agent view, נכנסים כשרוצים את השיחה המלאה, ולוחצים `←` כדי לחזור לטבלה.

## איך שולחים משימה לרקע ישירות מה-shell?
מוסיפים `--bg`. ה-prompt הוא ארגומנט רגיל, לא ערך של `-p`:

```bash
claude --bg "investigate the flaky SettingsChangeDetector test"
```

`--name` קובע את שם השורה במקום השם שנוצר אוטומטית:

```bash
claude --bg --name "flaky-test-fix" "investigate the flaky SettingsChangeDetector test"
```

Claude מדפיס מזהה קצר ואת הפקודות לניהול הסשן:

```text
backgrounded · 7c5dcf5d · flaky-test-fix
  claude agents             list sessions
  claude attach 7c5dcf5d    open in this terminal
  claude logs 7c5dcf5d      show recent output
  claude stop 7c5dcf5d      stop this session
```

`claude rm <id>` מסיר סשן מהרשימה. `claude agents --json` מדפיס את הסשנים כ-JSON, וזו הדרך הנתמכת לקרוא מצב סשנים מסקריפט. לא קוראים ישירות את הקבצים תחת `~/.claude/jobs/`.

## איך סשנים מקבילים לא דורסים זה את זה?
לפני עריכה ראשונה, Claude מעביר כל סשן רקע ל-[git worktree](/pro/worktrees) נפרד תחת `.claude/worktrees/`. כל הסשנים קוראים מאותו checkout, אבל כל אחד כותב לעותק משלו.

כשסשן כזה סיים לשנות קוד, Claude Code מנחה אותו לשמור את העבודה:

- **commit ו-push:** Claude עושה commit בלי לשאול, ו-push ל-branch אם יש remote.
- **draft pull request:** נפתח כשהמשימה מצדיקה זאת, והתווית `#N` מופיעה בשורה.
- **אף פעם לא:** push ל-`main` או `master`,‏ force-push או merge.
- **ההוראות שלך קובעות:** אם במשימה, ב-`CLAUDE.md` או בזיכרון כתוב שאת ה-commit וה-push אתה עושה בעצמך, Claude משאיר את git לך.

בסוף, Claude מדווח מה עשה ואיפה העבודה נמצאת: נתיב, branch,‏ pull request או התשובה עצמה.

אם worktrees לא מתאימים לריפו, אפשר לכבות את הבידוד ב-`.claude/settings.json` של הפרויקט. אז סשני הרקע עורכים ישירות את עותק העבודה:

```json
{
  "worktree": {
    "bgIsolation": "none"
  }
}
```

<Callout type="warning">
מחיקת סשן ב-agent view (`Ctrl+X` פעמיים) מסירה גם את ה-worktree ש-Claude יצר לו, **כולל שינויים שלא נשמרו ב-commit**. עשה commit למה שרוצים לשמור לפני שמוחקים. יש מקרים שבהם ה-worktree נשמר, למשל כשסשן אחר משתמש בו או כשיש בו commits שלא נדחפו. תמליל השיחה נשאר במחשב וזמין דרך `claude --resume`.
</Callout>

## אילו קיצורי מקלדת כדאי להכיר?
`?` בתוך agent view מציג את כל הקיצורים. אלה העיקריים:

| קיצור | פעולה |
| --- | --- |
| `↑` / `↓` | מעבר בין שורות |
| `Enter` | כניסה לסשן, או שליחה אם יש טקסט בשורה |
| `Space` | פתיחה או סגירה של פאנל ההצצה |
| `Ctrl+T` | הצמדה של סשן למעלה, והשארת התהליך שלו פעיל |
| `Ctrl+R` | שינוי שם לסשן |
| `Ctrl+S` | מעבר בין קיבוץ לפי מצב לקיבוץ לפי תיקייה |
| `Ctrl+X` | עצירת סשן; לחיצה נוספת תוך שתי שניות מוחקת אותו |
| `Esc` | סגירת הפאנל, ניקוי השורה או יציאה |

כדי למצוא סשן, מקלידים מסנן בשורת השליחה: `s:working` מציג רק סשנים שעובדים, ו-`s:blocked` מציג את כל מה שמחכה לך.

## מה המגבלות?
- **מכסה:** סשני רקע צורכים מהמנוי כמו סשנים רגילים. עשרה סשנים במקביל צורכים מכסה בערך פי עשרה מהר יותר.
- **מקומי:** הסשנים רצים על המחשב שלך. הם נשמרים בשינה, אבל נעצרים כשהמחשב כבה.
- **מחיקה:** worktree ש-Claude יצר נמחק יחד עם הסשן ב-agent view, חוץ מכמה מקרים שבהם הוא נשמר.

אפשר לכבות את agent view לגמרי עם ההגדרה `disableAgentView` או משתנה הסביבה `CLAUDE_CODE_DISABLE_AGENT_VIEW`. פרטים נוספים, כולל הגדרות הרשאות לסשנים ששולחים ופתרון תקלות, נמצאים ב[דף הרשמי](https://code.claude.com/docs/en/agent-view).
