Claude Code כולל מצב קורא מסך שמחליף את הממשק החזותי בטקסט לינארי עם תוויות, שקוראי מסך כמו VoiceOver ו-NVDA מקריאים לפי הסדר. מפעילים אותו עם `claude --ax-screen-reader`. למגדיל מסך, תנועה מופחתת ועיוורון צבעים יש הגדרות נפרדות.

## למה זה חשוב
הממשק הרגיל של Claude Code בנוי ממסגרות, אנימציות התקדמות ושורות שמתעדכנות במקום. לקורא מסך זה רעש. במצב קורא מסך Claude Code מדפיס שורות פשוטות עם תווית, כך שאפשר לנהל שיחה שלמה, לאשר הרשאות ולקרוא את הפלט מתחילתו ועד סופו.

המצב דורש הפעלה יזומה. הוא משנה רק את ממשק הטרמינל, ולכן לא צריך אותו בחלונית הצ'אט של תוסף VS Code. שם התוסף מקריא את פעילות השיחה לקורא המסך בלי הגדרה ([פרטים בתיעוד של VS Code](https://code.claude.com/docs/en/vs-code#use-a-screen-reader)).

## איך מפעילים את מצב קורא המסך?
בוחרים שיטה לפי התדירות:

| לכמה זמן | מה עושים |
| --- | --- |
| סשן אחד | מריצים `claude --ax-screen-reader` |
| כל סשן שנפתח מאותו shell | מגדירים את משתנה הסביבה `CLAUDE_AX_SCREEN_READER` לערך `1` |
| כל סשן במחשב | מוסיפים `"axScreenReader": true` לקובץ ה-[settings](/advanced/settings) של המשתמש |

לסשן אחד:

<CommandBlock>claude --ax-screen-reader</CommandBlock>

משתנה הסביבה ב-Bash או Zsh:

```bash
export CLAUDE_AX_SCREEN_READER=1
```

וב-PowerShell:

```powershell
$env:CLAUDE_AX_SCREEN_READER = "1"
```

כדי שהמשתנה יישאר גם ב-shells הבאים, מוסיפים את השורה לקובץ ה-profile של ה-shell. ההגדרה `axScreenReader` חלה בכל טרמינל, כולל הטרמינל המובנה של VS Code.

אם משלבים כמה שיטות, הדגל גובר על משתנה הסביבה, ומשתנה הסביבה גובר על ההגדרה. כשעובדים דרך SSH, מגדירים את המשתנה או ההגדרה במחשב המרוחק שבו Claude Code רץ.

השורה הראשונה ש-Claude Code מדפיס מאשרת את המצב ואת המקור שלו, למשל `[Screen Reader Mode: on via flag]`,‏ `on via env` או `on via settings`.

### איך מכבים אותו?
הופכים את השיטה שהפעילה אותו: מפעילים בלי הדגל, מבטלים את משתנה הסביבה, או משנים את `axScreenReader` ל-`false`. אם מגדירים `CLAUDE_AX_SCREEN_READER` לערך `0`, המצב נשאר כבוי גם כשההגדרה היא `true`.

## מה קורא המסך שומע?
במצב הזה Claude Code כותב טקסט שטוח:

- בלי תווי מסגרת בממשק.
- בלי רמזים שמבוססים רק על צבע.
- בלי ציור מחדש של תוכן שלא השתנה. ה-spinners מוצגים כטקסט קבוע.
- טבלאות בתשובות של Claude נקראות כמשפטים בצורה `Header: value`, ולא כרשת של תווי מסגרת.

כל מה שמודפס נשאר ב-scrollback של הטרמינל, כך שאפשר לחזור לתורות קודמים עם פקודות הסקירה של קורא המסך או עם החיפוש של הטרמינל.

### אילו תוויות יש בתמליל?
כל הודעה מתחילה בתווית שקורא המסך מקריא. אפשר גם לחפש אותן ב-scrollback כדי לקפוץ בין חלקי התמליל:

| תווית | משמעות |
| --- | --- |
| `you:` | ההודעות שלך |
| `claude:` | התשובות של Claude |
| `thinking:` | החשיבה של Claude |
| `tool:` | פעילות של כלי, כמו עריכת קובץ או הרצת פקודה |
| `tool error:` | כלי שנכשל |
| `error:` | שגיאה בשיחה, כמו בקשת API שנכשלה |
| `warning:` | אזהרה מ-Claude Code |
| `Permission Required:` | בקשת הרשאה שמחכה לתשובה שלך |
| `Cost:` | סיכום העלות ביציאה, אם החשבון שלך מציג עלויות |

### מה קורה בזמן שמקלידים?
- הסמן נשאר במקום ההקלדה, כך שהפקודה של קורא המסך לקריאת השורה הנוכחית מקריאה את הפרומפט שאתה עורך.
- כשמקלידים או מוחקים בסוף השורה, Claude Code כותב רק את התווים שהשתנו, וקורא המסך מקריא רק אותם.
- כשמוחקים מילה או שורה בקיצורי עריכה, כמו `Ctrl+W`,‏ `Ctrl+U` או `Ctrl+K`, Claude Code מקריא את הטקסט שנמחק.
- כשעוברים בין [מצבי הרשאות](/beginner-plus/permission-modes) עם `Shift+Tab`, Claude Code מכריז על המצב החדש, למשל `[plan mode on]`.

### למה יש השהיות קצרות?
Claude Code מחכה בשתי נקודות כדי שקורא המסך יספיק:

- אחרי שורת האישור הוא מחכה 3 שניות לפני שהוא מציג את הפרומפט. כל מקש מקצר את ההמתנה. את האורך משנים עם `CLAUDE_AX_STARTUP_QUIET_MS`.
- לפני שהוא כותב שורה חדשה או שורה שהשתנתה, הוא מזיז את הסמן לתחילת השורה ומחכה 50 מילישניות, כדי שקורא המסך יקרא אותה מהתו הראשון. את האורך משנים עם `CLAUDE_AX_PREPARK_MS`.

### איך קופצים בין תורות?
Claude Code מסמן את הגבולות בין התורות, כך שמקש המעבר לפרומפט הקודם בטרמינל קופץ בין תורות:

| טרמינל | מקש |
| --- | --- |
| iTerm2 | `Cmd+Shift+Up` |
| הטרמינל של VS Code | `Ctrl+Up` ב-Windows,‏ `Cmd+Up` ב-macOS |
| Windows Terminal | אין מקש כברירת מחדל. מקצים את הפעולה `scrollToMark` בהגדרות הטרמינל |
| Kitty ו-Ghostty | בודקים בתיעוד של הטרמינל מהו מקש המעבר לפרומפט הקודם |

ב-macOS Terminal וב-WezTerm זה לא עובד. שם מחפשים ב-scrollback את התווית `you:`.

## איך עונים על תפריטים ובקשות הרשאה?
תפריטים שבדרך כלל מנווטים בהם עם החצים, כולל בקשות הרשאה, הופכים לרשימות ממוספרות. Claude Code מקריא כל אפשרות כשורה עם מספר, ואחריה בקשת `Enter selection` עם הטווח החוקי. מקלידים את המספר ולוחצים Enter.

- כשהבקשה מסתיימת ב-`or Escape to cancel`, לוחצים Escape כדי לבטל.
- אם מקלידים מספר שלא ברשימה, Claude Code מקריא את הטווח החוקי ונותן לנסות שוב.
- בשאלות כן/לא מקלידים `y` או `n` ולוחצים Enter. גם `yes` ו-`no` עובדים.

גם הבורר של `/effort`, שהוא slider מחוץ למצב הזה, הופך לרשימה ממוספרת.

## איך יודעים ש-Claude Code מחכה לך?
במצב קורא מסך Claude Code משמיע את הצליל הרגיל של הטרמינל (terminal bell) כשהוא צריך את תשומת הלב שלך:

- Claude סיים תשובה.
- בקשה או חלון דו-שיח מחכים לתשובה, כמו בקשת הרשאה.
- כלי שרץ יותר מ-5 שניות הסתיים.

כדי להשתיק את הצליל, משנים את הגדרת ה-bell ביישום הטרמינל.

## אילו הגדרות נגישות יש מלבד קורא מסך?
לא חייבים להפעיל את מצב קורא המסך כדי לקבל התאמות אחרות:

| צורך | מה מגדירים | מה זה עושה |
| --- | --- | --- |
| מגדיל מסך | משתנה הסביבה `CLAUDE_CODE_ACCESSIBILITY=1` | סמן טרמינל שנשאר גלוי ועוקב אחרי מיקום ההקלדה, כדי שמגדיל כמו macOS Zoom יעקוב אחריו |
| פחות תנועה | ההגדרה `prefersReducedMotion` עם `true` | מפחית או מבטל spinners, הבהובים ואנימציות אחרות |
| עיוורון צבעים | ההגדרה `theme`, או הפקודה `/theme` | ערכות הצבעים `dark-daltonized` ו-`light-daltonized` |
| התראה בלי קורא מסך | ההגדרה `preferredNotifChannel` עם `"terminal_bell"` | צליל terminal bell כש-Claude מחכה לך |

את שמות ההגדרות המדויקים וערכיהן אפשר לבדוק ב-[settings reference](https://code.claude.com/docs/en/settings-reference).

## מה עדיין לא מותאם?
<Callout type="warning">
יש התנהגויות שהמצב לא מכסה:

- הוא לא נדלק אוטומטית כשקורא מסך פועל.
- שינוי של מצב הרשאות בדרך אחרת מ-`Shift+Tab`, כמו כניסה ל-plan mode מפקודה, לא מוכרז.
- חיבור לסשן ברקע עם `claude attach` פותח מסך חלופי בלי scrollback. כדי לצאת לוחצים חץ שמאלה על פרומפט ריק, או `Ctrl+Z` אם חלון דו-שיח בפוקוס.
- העלות מוכרזת רק בסיכום ביציאה, לא אחרי כל תור.
- המצב לא משנה את המצב הלא-אינטראקטיבי עם `-p`, שכבר כותב טקסט פשוט ומתאים לסקריפטים.
</Callout>

אם משהו לא עובד עם קורא המסך, המגדיל או הטרמינל שלך, פותחים issue ב-[Claude Code issue tracker](https://github.com/anthropics/claude-code/issues). מציינים בכותרת את טכנולוגיית העזר, ובגוף את מערכת ההפעלה, הטרמינל, ושם וגרסה של טכנולוגיית העזר.
