הקיצורים השימושיים ביותר: `Esc` עוצר את Claude באמצע, `Esc` פעמיים חוזר אחורה, `Shift+Tab` מחליף מצב הרשאות, `!` מריץ פקודת shell ישירות, `@` מאזכר קובץ, ו-`Ctrl+R` מחפש בהיסטוריה. `?` בשורה ריקה מציג את כל הקיצורים, ו-`/keybindings` מאפשר לשנות אותם.

## למה זה חשוב
רוב העבודה עם Claude Code קורית בשורת הקלט. מי שמכיר את הקיצורים עוצר את Claude ברגע שהוא הולך לכיוון לא נכון, במקום לחכות שיסיים. הוא גם בודק תוצאה של פקודה בלי לנסח בקשה, ושואל שאלה קטנה בלי לפזר את השיחה. חשוב לדעת: הקיצורים יכולים להשתנות לפי מערכת ההפעלה והטרמינל.

## אילו קיצורים כדאי להכיר קודם?
אלה הקיצורים שמשתמשים בהם כל יום:

| קיצור | מה הוא עושה |
| --- | --- |
| `Esc` | עוצר את התשובה או את הפעולה הנוכחית. Claude שומר את מה שכבר עשה, ואפשר לכוון אותו מחדש. כשחלון דו-שיח פתוח, סוגר אותו |
| `Esc` + `Esc` | כשיש טקסט בשורת הקלט: מנקה אותו ושומר אותו בהיסטוריה. כששורת הקלט ריקה: פותח את תפריט ה-rewind לחזרה לנקודה קודמת |
| `Ctrl+C` | עוצר פעולה שרצה. כשאין פעולה שרצה, לחיצה ראשונה מנקה את הקלט ולחיצה שנייה יוצאת |
| `Ctrl+D` | יוצא מהסשן. לחיצה ראשונה מציגה רמז, ולחיצה שנייה תוך 800ms יוצאת |
| `Shift+Tab` | מחליף בין מצבי ההרשאות |
| `Up` / `Down` (חצים) | מזיז את הסמן בפרומפט של כמה שורות, ובשורה הראשונה או האחרונה עובר בהיסטוריית הפרומפטים |
| `Ctrl+R` | חיפוש אחורה בהיסטוריית הפרומפטים |
| `Ctrl+O` | פותח וסוגר את תצוגת ה-transcript, עם פירוט הכלים שרצו |
| `Ctrl+T` | מציג או מסתיר את רשימת המשימות (to-do) של Claude |
| `Ctrl+B` | מעביר פקודות Bash וסוכנים שרצים לרקע. ב-tmux לוחצים פעמיים |
| `Ctrl+G` | פותח את הפרומפט בעורך הטקסט ברירת המחדל שלך |
| `Ctrl+S` | שומר את הפרומפט בצד ומנקה את השורה. לחיצה נוספת על שורה ריקה מחזירה אותו |
| `?` בשורה ריקה | פותח וסוגר את חלונית עזרת הקיצורים |

<Callout type="tip">
`Esc` הוא הקיצור החשוב ביותר לעבודה יומיומית. אם Claude התחיל לערוך את הקובץ הלא נכון, לוחצים `Esc` וכותבים לו מה לתקן. לא צריך לחכות שיסיים ולא צריך להתחיל מחדש.
</Callout>

## מה שונה בין macOS ל-Windows ו-Linux?
חלק מהקיצורים תלויים במערכת. אלה ההבדלים שהתיעוד הרשמי מציין:

| פעולה | macOS | Windows / Linux |
| --- | --- | --- |
| החלפת מודל בלי למחוק את הפרומפט | `Option+P` | `Alt+P` |
| הפעלה וכיבוי של extended thinking | `Option+T` | `Alt+T` |
| הפעלה וכיבוי של fast mode | `Option+O` | `Alt+O` |
| הדבקת תמונה מהלוח | `Ctrl+V`, או `Cmd+V` ב-iTerm2 | Linux: `Ctrl+V`. Windows: `Alt+V`. ב-WSL שניהם עובדים |
| השהיית Claude Code (חוזרים עם `fg`) | `Ctrl+Z` | Linux: `Ctrl+Z`. התיעוד מסמן את הקיצור כ-Unix בלבד |

שתי הערות מהתיעוד:

- **macOS:** קיצורי Option/Alt כמו `Alt+B`,‏ `Alt+F`,‏ `Alt+D`,‏ `Alt+Y` ו-`Alt+P` דורשים להגדיר בטרמינל את Option כ-Meta. ההוראות לכל טרמינל נמצאות ב[דף הגדרות הטרמינל](https://code.claude.com/docs/en/terminal-config#enable-option-key-shortcuts-on-macos). את `Option+T` אפשר להפעיל גם בלי ההגדרה הזו.
- **Windows:** כשסביבת ההרצה (Node או Bun) לא מפעילה VT input mode, החלפת מצב ההרשאות היא `Alt+M` במקום `Shift+Tab`.

המודלים הזמינים מתחלפים. לרשימה העדכנית מריצים `/model` או רואים את [דף הגדרות המודל](https://code.claude.com/docs/en/model-config).

## איך כותבים פרומפט בכמה שורות?
`Enter` שולח את ההודעה, ולכן צריך דרך אחרת לרדת שורה:

| שיטה | קיצור | איפה זה עובד |
| --- | --- | --- |
| לוכסן הפוך | `\` ואז `Enter` | בכל הטרמינלים |
| תו בקרה | `Ctrl+J` | בכל טרמינל, בלי הגדרות |
| Shift+Enter | `Shift+Enter` | מובנה ב-iTerm2,‏ WezTerm,‏ Ghostty,‏ Kitty,‏ Warp,‏ Apple Terminal ו-Windows Terminal |
| מקש Option | `Option+Enter` | ב-macOS, אחרי הגדרת Option כ-Meta |
| הדבקה | מדביקים ישירות | לבלוקי קוד ולוגים |

## מה עושים התווים המיוחדים בשורת הקלט?
תו אחד בשורת הקלט פותח מצב אחר:

| תו | מה הוא פותח |
| --- | --- |
| `/` בתחילת השורה | תפריט הפקודות וה-skills. אפשר להמשיך להקליד כדי לסנן |
| `!` בתחילת השורה | shell mode: הרצת פקודה ישירות |
| `@` | השלמה אוטומטית של נתיב קובץ, כדי לאזכר קובץ בפרומפט |

## איך מריצים פקודת shell בלי לבקש מ-Claude?
מתחילים את השורה ב-`!`. הפקודה רצה ישירות, בלי ש-Claude מפרש אותה:

```bash
! npm test
! git status
```

מה קורה ב-shell mode:

- הפקודה והפלט שלה נכנסים להקשר של השיחה.
- Claude מגיב לפלט אוטומטית. למשל, אחרי `! npm test` תקבל הסבר על הבדיקות שנכשלו בלי לכתוב פרומפט נוסף. התגובה עולה כמו שליחת פרומפט רגיל.
- `Tab` משלים פקודה מתוך פקודות `!` קודמות באותו פרויקט.
- `Ctrl+B` מעביר פקודה ארוכה לרקע.
- יוצאים עם `Esc`,‏ `Backspace` או `Ctrl+U` כששורת הקלט ריקה.

<Callout type="warning">
ב-shell mode הפקודה לא עוברת דרך אישור של Claude. היא רצה ברגע שהיא נשלחת (או בסוף הסבב, אם Claude באמצע עבודה), אז בודקים אותה לפני השליחה.
</Callout>

## מה קורה כשכותבים הודעה בזמן ש-Claude עובד?
ההודעה נכנסת לתור ולא קוטעת את Claude. ההודעות בתור מוצגות מעל שורת הקלט עד שהן נשלחות:

- **הודעה רגילה:** אם Claude באמצע קריאות לכלים, הוא מקבל אותה כשהן מסתיימות, באותו סבב (turn). הודעות שנשארו בתור נשלחות לפי הסדר כשהסבב מסתיים.
- **פקודות ופקודות `!`:** מחכות לסוף הסבב ורצות אחת אחרי השנייה.
- **לשלוח עכשיו:** `Ctrl+Enter` קוטע את הסבב ושולח את מה שבתור מיד. בטרמינל שלא מזהה את `Ctrl+Enter`, משתמשים ב-`Ctrl+X` ואז `Ctrl+S`.
- **להחזיר מהתור:** חץ למעלה (`Up`) מהשורה הראשונה מחזיר את ההודעות מהתור לשורת הקלט, כדי לערוך אותן.

זה שימושי כשנזכרים בפרט באמצע עבודה, כמו "וגם תעדכן את הבדיקות", בלי לעצור את Claude.

## איך שואלים שאלה צדדית בלי לפזר את השיחה?
מריצים `/btw` עם השאלה. זו הדוגמה מהתיעוד הרשמי:

```text
/btw what was the name of that config file again?
```

Claude עונה ממה שכבר נמצא בשיחה, והשאלה והתשובה לא נכנסות להיסטוריית השיחה. התשובה מופיעה בחלון צף, וסוגרים אותו עם `Space`,‏ `Enter` או `Esc`.

- **עובד גם בזמן ש-Claude עובד:** השאלה לא קוטעת את הסבב הנוכחי.
- **בלי כלים:** Claude לא קורא קבצים ולא מריץ פקודות כדי לענות. הוא עונה רק ממה שכבר בהקשר.
- **תשובה אחת:** אין המשך שיחה בחלון. לשאלה נוספת מריצים `/btw` שוב.

כלל אצבע מהתיעוד: `/btw` לשאלות על מה ש-Claude כבר יודע מהסשן. כדי לברר משהו חדש, משתמשים ב-subagent.

## איך מוצאים פרומפט שכתבתי קודם?
Claude Code שומר את הפרומפטים שהקלדת, לכל תיקיית עבודה בנפרד. חץ למעלה (`Up`) מחזיר פרומפטים קודמים, גם מסשנים קודמים באותו פרויקט.

לחיפוש לוחצים `Ctrl+R` ומקלידים חלק מהטקסט. כך זה עובד בתצוגה הרגילה (classic renderer):

- `Ctrl+R` שוב עובר להתאמה ישנה יותר.
- `Tab` או `Esc` מכניסים את ההתאמה לשורת הקלט כדי לערוך אותה.
- `Enter` מכניס ושולח מיד.
- `Ctrl+C` מבטל ומחזיר את מה שהיה בשורה.

ב-[fullscreen rendering](https://code.claude.com/docs/en/fullscreen), `Ctrl+R` פותח חלון חיפוש: `Enter` או `Tab` מכניסים את ההתאמה לשורת הקלט, ו-`Esc` מבטל.

## אילו קיצורים עוזרים לערוך את הפרומפט?
Claude Code משתמש בקיצורי עריכה בסגנון readline:

| קיצור | מה הוא עושה |
| --- | --- |
| `Ctrl+A` / `Ctrl+E` | קפיצה לתחילת השורה / לסוף השורה |
| `Ctrl+U` | מחיקה מהסמן עד תחילת השורה |
| `Ctrl+K` | מחיקה מהסמן עד סוף השורה |
| `Ctrl+W` | מחיקה אחורה עד הרווח הקודם. לחיצה אחת מוחקת נתיב שלם |
| `Ctrl+Y` | מדביק את הטקסט האחרון שנמחק באחד מקיצורי המחיקה |
| `Ctrl+_` | מבטל את העריכה האחרונה בשורת הקלט |

מי שמעדיף vim מפעיל אותו ב-`/config` תחת Editor mode.

## איך משנים קיצור מקלדת?
מריצים בתוך הסשן:

<CommandBlock>/keybindings</CommandBlock>

הפקודה יוצרת או פותחת את הקובץ `~/.claude/keybindings.json`. כל בלוק בקובץ מגדיר הקשר (context), למשל `Chat` לשורת הקלט, ומיפוי של מקשים לפעולות. בדוגמה מה[תיעוד הרשמי של keybindings](https://code.claude.com/docs/en/keybindings), `Ctrl+E` פותח עורך חיצוני ו-`Ctrl+U` מבוטל עם `null`:

```json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "$docs": "https://code.claude.com/docs/en/keybindings",
  "bindings": [
    {
      "context": "Chat",
      "bindings": {
        "ctrl+e": "chat:externalEditor",
        "ctrl+u": null
      }
    }
  ]
}
```

Claude Code מזהה שינויים בקובץ ומחיל אותם בלי הפעלה מחדש. אם יש שגיאה, כמו שם פעולה לא מוכר, הוא מציג אזהרה.

<Callout type="note">
את `Ctrl+C` ואת `Ctrl+D` אי אפשר לשנות. גם קיצורי התנועה והמחיקה לפי מילים, כמו `Ctrl+W` ו-`Alt+B`, לא ניתנים למיפוי מחדש בקובץ, כי אין בו פעולות עבורם.
</Callout>
