ביום הראשון מספיקות כמה פקודות: `/help` מציג עזרה ואת הפקודות הזמינות, `/clear` פותח שיחה חדשה, `/resume` חוזר לשיחה קודמת, `/diff` מציג מה השתנה, `/rewind` מחזיר אחורה, ו-`/exit` יוצא. מקלידים `/` כדי לראות את כל הפקודות שזמינות לך.

## למה זה חשוב
פקודות הן הדרך לשלוט ב-Claude Code עצמו: לנהל שיחות, לבדוק שינויים, להחליף מודל ולפתור תקלות. יש עשרות פקודות, אבל רוב העבודה היומיומית נשענת על כמה בודדות. השיעור הזה מרכז אותן, והוא גם השיעור האחרון ברמה 0.

## איך פקודות עובדות?
- מקלידים `/` כדי לפתוח את תפריט הפקודות, או `/` ואחריו כמה אותיות כדי לסנן.
- פקודה מזוהה רק בתחילת ההודעה. טקסט שבא אחרי שם הפקודה עובר אליה כארגומנט.
- אם שולחים פקודה בזמן ש-Claude עונה, היא נכנסת לתור ורצה כשהתשובה הנוכחית מסתיימת. חלק מהפקודות, כמו `/status` ו-`/usage`, רצות מיד.

## אילו פקודות צריך מהיום הראשון?

| פקודה | מה היא עושה |
| --- | --- |
| `/help` | מציג עזרה ואת הפקודות הזמינות |
| `/clear` | פותח שיחה חדשה עם הקשר ריק |
| `/resume` | חוזר לשיחה קודמת, לפי שם או מתוך רשימה |
| `/diff` | מציג את השינויים בתיקיית העבודה, כולל העריכות של Claude |
| `/rewind` | מחזיר את השיחה ו/או הקוד לנקודה קודמת |
| `/status` | מציג גרסה, מודל, חשבון וחיבוריות |
| `/usage` | מציג עלות הסשן, מגבלות השימוש של התוכנית וסטטיסטיקות |
| `/exit` | יוצא מ-Claude Code |

## ומה עוד כדאי להכיר?
אלה פקודות שתפגוש ברמות הבאות. התיעוד הרשמי מסדר אותן לפי שלב בעבודה:

- **בסשן הראשון בפרויקט:** `/init` יוצר קובץ `CLAUDE.md` התחלתי עם הנחיות לפרויקט, ו-`/memory` עורך אותו.
- **בזמן משימה:** `/model` מחליף מודל. כשהשיחה ארוכה, `/context` מראה מה ממלא את חלון ההקשר, ו-`/compact` מסכם את השיחה כדי לפנות מקום.
- **כשמשהו לא עובד:** `/doctor` מריץ בדיקת הגדרות ויכול לתקן בעיות. מחוץ לסשן אפשר להריץ `claude doctor` לאבחון בלבד.
- **חשבון:** `/login` ו-`/logout` מתחברים ומתנתקים.

<Callout type="note">
לא כל פקודה מופיעה לכל משתמש. הזמינות תלויה בפלטפורמה, בתוכנית ובסביבה. אם פקודה מהשיעור לא מופיעה אצלך, זו לא בהכרח תקלה.
</Callout>

## `/clear` או `/compact`?
שתיהן עוזרות כשהשיחה מתארכת, אבל עושות דברים שונים:

- **`/clear`** מתחיל משימה חדשה: שיחה חדשה עם הקשר ריק. אפשר לחזור לשיחה הקודמת עם `/resume`.
- **`/compact`** ממשיך את אותה משימה: הוא מסכם את השיחה עד עכשיו כדי לפנות מקום. אפשר להוסיף הנחיה למה להתמקד בסיכום.
