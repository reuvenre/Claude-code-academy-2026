פותחים טרמינל בתיקיית הפרויקט, מריצים `claude` ומתחילים בשאלה על הקוד, למשל `what does this project do?`. Claude Code קורא את הקבצים לבד לפי הצורך. מקלידים `/help` כדי לראות את הפקודות הזמינות, ו-`/exit` כדי לצאת.

## למה זה חשוב
הסשן הראשון קובע את ההרגל. מי שמתחיל בשאלות על הקוד, לפני שמבקש שינויים, מבין מהר מה Claude Code רואה ואיך הוא חושב. זה גם הרגע ללמוד כמה פקודות בסיס שישמשו אותך כל יום.

## איך פותחים סשן?

<StepList>

1. פותחים טרמינל ועוברים לתיקיית הפרויקט. מחליפים את הנתיב בנתיב של הפרויקט שלך:
   ```bash
   cd /path/to/your/project
   ```
2. מפעילים את Claude Code:
   <CommandBlock>claude</CommandBlock>
3. מעל שורת הקלט מוצגים מספר הגרסה, המודל הנוכחי ותיקיית העבודה. אפשר להתחיל לכתוב.

</StepList>

## מה שואלים קודם?
מתחילים בהבנת הפרויקט. אלה דוגמאות מהמדריך הרשמי:

```text
what does this project do?
```

```text
what technologies does this project use?
```

```text
where is the main entry point?
```

```text
explain the folder structure
```

Claude ינתח את הקבצים ויחזיר סיכום. לא צריך להוסיף הקשר ידנית: Claude Code קורא את קובצי הפרויקט לבד כשהוא צריך אותם.

אפשר לשאול אותו גם על עצמו, למשל `what can Claude Code do?`.

<Callout type="tip">
היה ספציפי. במקום "fix the bug", כתוב מה הבאג: למשל שמשתמשים רואים מסך ריק אחרי שהזינו פרטים שגויים. ככל שהבקשה מדויקת יותר, התוצאה טובה יותר.
</Callout>

## אילו פקודות צריך לדעת מהיום הראשון?
יש שני סוגים של פקודות: פקודות **shell**, שמריצים בטרמינל כדי להפעיל את Claude Code, ופקודות **סשן**, שמקלידים בתוך Claude Code אחרי שהוא רץ.

**פקודות shell:**

| פקודה | מה היא עושה |
| --- | --- |
| `claude` | פותח סשן אינטראקטיבי |
| `claude "task"` | פותח סשן עם בקשה ראשונה |
| `claude -p "query"` | מריץ שאילתה אחת ויוצא |
| `claude -c` | ממשיך את השיחה האחרונה בתיקייה הנוכחית |
| `claude -r` | חוזר לשיחה קודמת מתוך רשימה |

**פקודות סשן:**

| פקודה | מה היא עושה |
| --- | --- |
| `/help` | מציג את הפקודות הזמינות |
| `/resume` | ממשיך שיחה קודמת |
| `/clear` | מנקה את היסטוריית השיחה |
| `/exit` או `Ctrl+D` פעמיים | יוצא מ-Claude Code |

## קיצורי מקלדת שחוסכים זמן
- מקלידים `/` כדי לראות את הפקודות וה-skills הזמינים.
- `Tab` משלים פקודות.
- `↑` מחזיר הודעות קודמות.
- `Shift+Tab` מחליף מצב הרשאות. נרחיב עליו ברמה 1.
