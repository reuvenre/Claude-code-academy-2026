Claude Code הוא כלי קוד אג׳נטי של Anthropic: הוא קורא את הקוד שלך, עורך קבצים, מריץ פקודות ומתחבר לכלי הפיתוח שלך. בניגוד לעוזר שמשלים שורה בקובץ הפתוח, הוא רואה את כל הפרויקט ומבצע משימה שלמה. אפשר לעבוד איתו בטרמינל, ב-IDE, באפליקציית דסקטופ ובדפדפן.

## למה זה חשוב
כי אתה מתאר מטרה, ו-Claude Code מבצע את הדרך אליה. הוא בונה פיצ׳רים, מתקן באגים ומאוטמט משימות פיתוח, ועובד על פני כמה קבצים וכלים כדי לסיים את העבודה.

ההבדל מעוזר קוד רגיל הוא בהיקף. עוזר השלמה רואה בעיקר את הקובץ הנוכחי. כשמבקשים מ-Claude Code לתקן באג, הוא מחפש את הקבצים הרלוונטיים, קורא אותם כדי להבין את ההקשר, עורך כמה קבצים באופן מתואם, מריץ בדיקות כדי לוודא שהתיקון עובד, ומבצע commit אם ביקשת.

## מה אפשר לעשות איתו?
לפי התיעוד הרשמי, אלה השימושים המרכזיים:

- **משימות שדוחים:** כתיבת בדיקות לקוד שאין לו, תיקון שגיאות lint בכל הפרויקט, פתרון merge conflicts, עדכון תלויות וכתיבת release notes.
- **פיצ׳רים ובאגים:** מתארים בשפה רגילה מה רוצים. Claude Code מתכנן את הגישה, כותב קוד בכמה קבצים ובודק שהוא עובד. בבאג מדביקים הודעת שגיאה או מתארים את הסימפטום, והוא מאתר את שורש הבעיה.
- **Git:** מכין שינויים ל-commit, כותב הודעות commit, יוצר branches ופותח pull requests.
- **חיבור לכלים חיצוניים:** דרך MCP, תקן פתוח לחיבור כלי AI למקורות מידע, כמו Google Drive,‏ Jira או Slack.
- **התאמה אישית:** קובץ CLAUDE.md עם הנחיות לפרויקט, skills לתהליכים שחוזרים על עצמם, ו-hooks שמריצים פקודות לפני או אחרי פעולות של Claude.
- **אוטומציה:** הרצה בסקריפטים וב-CI, משימות מתוזמנות, וכמה סוכנים שעובדים במקביל.

אין צורך ללמוד את כל זה עכשיו. הרמות הבאות בקורס מכסות כל נושא בנפרד.

## איפה משתמשים ב-Claude Code?
Claude Code זמין בכמה משטחים (surfaces), וכולם מחוברים לאותו מנוע:

| משטח | מה זה |
| --- | --- |
| טרמינל (CLI) | הגרסה המלאה, שורת פקודה. עליה הקורס מתמקד |
| VS Code ו-Cursor | תוסף עם diffs בתוך העורך |
| JetBrains | תוסף ל-IntelliJ,‏ PyCharm,‏ WebStorm ודומיהן |
| אפליקציית דסקטופ | אפליקציה עצמאית, בלי טרמינל |
| דפדפן | בכתובת claude.ai/code, בלי התקנה מקומית |

כי כולם משתמשים באותו מנוע, קובץ CLAUDE.md, ההגדרות ושרתי ה-MCP של הפרויקט עובדים בכל אחד מהם.

<Callout type="note">
רוב המשטחים דורשים מנוי Claude או חשבון Anthropic Console. על סוגי החשבונות וההתחברות נרחיב בשיעור נפרד ברמה הזו.
</Callout>

## איך זה נראה בפועל?
אחרי ההתקנה, מפעילים את Claude Code מתוך תיקיית הפרויקט:

<CommandBlock>claude</CommandBlock>

אפשר גם לתת לו משימה כבר בהפעלה. זו דוגמה מהתיעוד הרשמי, שמבקשת לכתוב בדיקות למודול, להריץ אותן ולתקן כשלים:

```bash
claude "write tests for the auth module, run them, and fix any failures"
```

שים לב שלא ציינו אילו קבצים לקרוא או אילו פקודות להריץ. Claude Code מחליט על כך בעצמו תוך כדי עבודה. בשיעור הבא נראה בדיוק איך.
