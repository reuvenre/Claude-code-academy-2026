Claude Code עובד ישירות עם git, אז מבקשים במילים במקום להקליד פקודות: `what files have I changed?` כדי לראות שינויים, `commit my changes with a descriptive message` כדי לשמור אותם, ו-`create a new branch called feature/quickstart` כדי לפתוח branch. הוא מריץ את פקודות git בעצמו וכותב את הודעות ה-commit.

## למה זה חשוב
git הוא אחד הכלים שמתחילים הכי חוששים ממנו. עם Claude Code לא צריך לזכור תחביר: הוא מכין שינויים ל-commit, כותב הודעות commit, יוצר branches ופותח pull requests. אתה מתמקד במה שרוצים לעשות, ובודק את התוצאה.

## מה Claude Code רואה ב-git?
כשמפעילים את `claude` בתיקייה, Claude Code רואה:

- את ה-branch הנוכחי.
- שינויים שעוד לא נשמרו ב-commit.
- היסטוריית commits אחרונה.

כשעוברים ל-branch אחר, Claude רואה את הקבצים של ה-branch החדש, והשיחה עצמה נשארת כפי שהייתה.

## אילו בקשות כותבים?
אלה דוגמאות מהמדריך הרשמי:

| מה רוצים | מה כותבים ל-Claude |
| --- | --- |
| לראות מה השתנה | `what files have I changed?` |
| לשמור שינויים ב-commit | `commit my changes with a descriptive message` |
| לפתוח branch חדש | `create a new branch called feature/quickstart` |
| לראות היסטוריה | `show me the last 5 commits` |
| לפתור קונפליקטים | `help me resolve merge conflicts` |

## איך מכינים pull request?
אפשר לבקש ישירות `create a pr for my changes`, או להתקדם בשלבים:

<StepList>

1. מבקשים סיכום של השינויים:
   ```text
   summarize the changes I've made to the authentication module
   ```
2. מבקשים ליצור את ה-PR:
   ```text
   create a pr
   ```
3. משפרים את התיאור:
   ```text
   enhance the PR description with more context about the security improvements
   ```

</StepList>

<Callout type="tip">
לפני ששולחים את ה-PR, קוראים אותו ומבקשים מ-Claude להצביע על סיכונים או נקודות שכדאי לשים לב אליהן. זו המלצה מהתיעוד הרשמי.
</Callout>

## איך בודקים לפני שממשיכים?
commit נשמר אצלך במחשב, אבל push ו-pull request משתפים את העבודה עם אחרים. לכן כדאי לבדוק קודם:

- `/diff` מציג את כל השינויים בתיקיית העבודה.
- אפשר לשאול את Claude מה בדיוק הוא עשה ולמה.

<Callout type="warning">
checkpoints של Claude Code מחזירים קבצים מקומיים בלבד. פעולות שיוצאות מהמחשב, כמו push או פתיחת PR, אי אפשר להחזיר עם `Esc`. בדוק לפני שאתה מאשר אותן.
</Callout>

## דוגמה: סיכום commits מהטרמינל
Claude Code משתלב גם עם כלים אחרים בטרמינל. הדוגמה הזו מהתיעוד הרשמי מעבירה את 20 ה-commits האחרונים ל-Claude ומבקשת סיכום:

<CommandBlock>git log --oneline -20 | claude -p "summarize these recent commits"</CommandBlock>

`claude -p` מריץ בקשה אחת, מדפיס את התשובה ויוצא.
