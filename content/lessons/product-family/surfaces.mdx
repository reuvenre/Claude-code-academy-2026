Claude Code רץ בטרמינל (CLI), באפליקציית הדסקטופ, ב-VS Code וב-JetBrains, בדפדפן (ווב) ובאפליקציית Claude לנייד. בכולם פועל אותו מנוע, וכל משטח מותאם לדרך עבודה אחרת. CLAUDE.md, ההגדרות ושרתי ה-MCP של הפרויקט עובדים בכולם, ואפשר להעביר סשן ממשטח למשטח.

## למה זה חשוב
בחירת משטח לא נכון עולה בזמן. משימה ארוכה בטרמינל נעצרת כשסוגרים את המחשב, ו-review של diff גדול נוח יותר בממשק גרפי. כשמכירים את המפה, בוחרים משטח לפי המשימה ולא לפי הרגל. בנוסף, לכל משטח יש בקורס שיעור מעמיק משלו, והשיעור הזה מחבר ביניהם.

## אילו משטחים יש, ולמה כל אחד מתאים?
התיעוד הרשמי מסכם את המשטחים כך:

| משטח | מתאים ל | מה מקבלים | שיעור מעמיק |
| --- | --- | --- | --- |
| CLI (טרמינל) | עבודה בטרמינל, סקריפטים, שרתים מרוחקים | סט היכולות המלא, Agent SDK, ספקי צד שלישי | [התקנה](/beginner/installation) |
| Desktop | review ויזואלי, סשנים במקביל, התקנה מנוהלת | diff viewer, תצוגה מקדימה של האפליקציה | [הדסקטופ](/pro/desktop) |
| VS Code | עבודה בתוך VS Code בלי לעבור לטרמינל | diffs בתוך העורך, טרמינל משולב, הקשר מהקבצים | [IDE](/pro/ide) |
| JetBrains | עבודה ב-IntelliJ,‏ PyCharm,‏ WebStorm ו-IDEs נוספים | diff viewer, שיתוף הבחירה בעורך, סשן בטרמינל | [IDE](/pro/ide) |
| Web | משימות ארוכות שלא דורשות הרבה הכוונה, או עבודה שצריכה להמשיך כשאתה לא מחובר | ענן שמנוהל כברירת מחדל על ידי Anthropic, ממשיך אחרי שמתנתקים | [הווב](/pro/web) |
| Mobile | התחלה ומעקב אחרי משימות כשאתה רחוק מהמחשב | סשנים בענן מאפליקציית Claude ל-iOS ול-Android, ‏Remote Control לסשנים מקומיים, Dispatch לדסקטופ ב-Pro וב-Max | [הנייד](/pro/mobile) |

כמה הבחנות מהתיעוד:

- **ה-CLI הוא המשטח המלא ביותר** לעבודה בטרמינל. סקריפטים וה-Agent SDK זמינים רק בו.
- **הדסקטופ וההרחבות ל-IDE** מוותרים על חלק מהיכולות של ה-CLI בתמורה ל-review ויזואלי ולשילוב הדוק בעורך.
- **הווב רץ בענן**, ולכן משימות ממשיכות גם אחרי שמתנתקים.
- **הנייד הוא לקוח דק:** הוא מתחבר לאותם סשנים בענן, או לסשן מקומי דרך Remote Control, ויכול לשלוח משימות לדסקטופ עם Dispatch.

<Callout type="note">
רוב המשטחים דורשים מנוי Claude או חשבון Anthropic Console. אפליקציית הדסקטופ כוללת את Claude Code ולא צריך להתקין את ה-CLI בנפרד, אבל היא דורשת מנוי בתשלום. הפלאגין ל-JetBrains, לעומת זאת, דורש את ה-CLI מותקן בנפרד. פרטים על ספקי צד שלישי יש ב[דף הפלטפורמות הרשמי](https://code.claude.com/docs/en/platforms).
</Callout>

## איך Claude Code מתחבר לכלים שכבר יש לך?
מעבר למשטחים שבהם עובדים, יש אינטגרציות שמביאות את Claude לכלים אחרים:

| אינטגרציה | מה היא עושה | שיעור מעמיק |
| --- | --- | --- |
| Chrome | שולט בדפדפן עם הסשנים שכבר מחוברים בו: בדיקת אפליקציות ווב, מילוי טפסים | [Chrome](/pro/chrome) |
| Slack | מגיב לאזכורי `@Claude` בערוצים, למשל כדי להפוך דיווח על באג ל-pull request | [Claude Tag ו-Slack](/pro/claude-tag) |
| Claude Tag | מריץ את `@Claude` כזהות משותפת של הארגון, עם גישה שהאדמין מגדיר, בתוכניות Team ו-Enterprise | [Claude Tag ו-Slack](/pro/claude-tag) |
| GitHub Actions ו-GitLab CI/CD | מריצים את Claude בתוך ה-CI | [CI/CD](/pro/ci-cd) |

לשירותים שלא מופיעים כאן מחברים שרתי MCP ו-connectors.

## מה משותף בין המשטחים?
כל משטח מתחבר לאותו מנוע של Claude Code. לכן, לפי [סקירת Claude Code הרשמית](https://code.claude.com/docs/en/overview), קובצי CLAUDE.md של הריפו, ההגדרות ושרתי ה-MCP עובדים בכולם. דף הפלטפורמות מנסח זאת כך: הגדרות, זיכרון הפרויקט ושרתי MCP משותפים בין המשטחים **המקומיים**.

המשמעות המעשית: אפשר לערבב משטחים על אותו פרויקט. כותבים CLAUDE.md פעם אחת, והוא נטען גם בטרמינל, גם בדסקטופ וגם ב-VS Code.

<Callout type="note">
מה שהתיעוד מתאר כמשותף הוא ההגדרות, זיכרון הפרויקט ושרתי ה-MCP. כדי להמשיך סשן מסוים במשטח אחר, התיעוד מפנה לכלי ההעברה שבסעיף הבא.
</Callout>

## איך מעבירים סשן ממשטח למשטח?
התיעוד הרשמי מתאר כמה דרכים להעביר עבודה בין משטחים:

| רוצה | משתמשים ב |
| --- | --- |
| להמשיך את סשן הטרמינל הנוכחי בדסקטופ, עם review ויזואלי של ה-diff | `/desktop` |
| למשוך לטרמינל משימה שהתחלת בווב או באפליקציית הנייד | `claude --teleport` |
| להתחיל משימה מקומית ולהמשיך אותה בנייד | `claude --cloud`, ואז אפליקציית Claude לנייד |
| לנהוג בסשן מקומי שכבר רץ מהטלפון או מדפדפן | [Remote Control](/pro/mobile) |
| לשלוח משימה מהטלפון לסשן חדש בדסקטופ | Dispatch (ב-Pro וב-Max) |

לדוגמה, מתוך סשן פתוח בטרמינל:

<CommandBlock>/desktop</CommandBlock>

וכדי למשוך סשן מהענן לטרמינל:

<CommandBlock>claude --teleport</CommandBlock>

`/desktop` ו-`--teleport` דורשים מנוי claude.ai. ‏`/desktop` זמין ב-macOS וב-Windows x64. על כל אחת מהדרכים יש פירוט בשיעורים [הווב](/pro/web), [הדסקטופ](/pro/desktop) ו[הנייד](/pro/mobile).

## איך בוחרים משטח בפועל?
שלוש שאלות קצרות מכסות את רוב המקרים:

- **איפה אתה עובד רוב היום?** בטרמינל: CLI. בתוך העורך: ההרחבה ל-VS Code או ל-JetBrains. מעדיף לא לעבוד בטרמינל: הדסקטופ.
- **המשימה צריכה להמשיך כשהמחשב סגור?** הווב, שרץ בענן.
- **אתה רחוק מהמחשב?** אפליקציית Claude לנייד, לסשנים בענן או לסשן מקומי דרך Remote Control.

אם אתה לא בטוח מאיפה להתחיל, התיעוד הרשמי ממליץ להתקין את ה-CLI ולהריץ אותו בתיקיית פרויקט. אחר כך מוסיפים משטחים לפי הצורך. ההגדרות וה-CLAUDE.md כבר יחכו לך שם.
