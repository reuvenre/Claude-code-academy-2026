Claude Academy היא אתר הלמידה הרשמי של Anthropic, עם קורסים ומדריכים לפי מוצר. ל-Claude Code מתחילים שם ב-Claude Code 101, ואחריו ממשיכים ל-Claude Code in action ולקורסים ממוקדים. בשיעור הזה יש מפה מכל שיעור באקדמיה לשיעור המקביל אצלנו, ורשימה של מה ללמוד אחרי הקורס.

## למה זה חשוב
הקורס שלנו והאקדמיה משלימים זה את זה. אצלנו הכול בעברית, מאומת מול התיעוד הרשמי ומחולק ל-68 שיעורים קצרים. באקדמיה יש קורסים ומדריכים באנגלית, ברובם עם quiz בסוף הקורס, ישירות מצוות החינוך של Anthropic. כשיודעים איזה שיעור מקביל לאיזה, אפשר לחזור על נושא בשני המקורות, למלא פערים, ולדעת לאן ממשיכים.

## מה יש בעמוד Claude Code של האקדמיה?
[עמוד Claude Code](https://academy.claude.com/products/code) באקדמיה מרכז את כל מה שקשור למוצר:

- **Start here:** הקורס [Claude Code 101](https://academy.claude.com/courses/claude-code-101).
- **Your first day:** התקנה, התחברות והשינוי הראשון. מפנה לתיעוד הרשמי.
- **Giving Claude context:** ‏CLAUDE.md והרגלי פרומפט. מפנה לתיעוד הרשמי.
- **For Admins and IT:** מדריכי setup,‏ governance ו-rollout לארגון.
- **Docs and reference:** קישורים לתיעוד ולמאמרים על MCP,‏ hooks,‏ skills,‏ subagents, תיקיית `.claude` וחלון ההקשר.
- **Browse it all:** כל ה-tutorials וכל הקורסים של Claude Code.

רוב הקישורים בעמוד מובילים ל-`code.claude.com`, אותו תיעוד רשמי שעליו מבוסס הקורס שלנו.

<Callout type="note">
בעמודי הקורסים מופיעה האפשרות Sign in to save progress. לקורסים שיש בהם quiz מופיע גם Completion badge. עמוד הבית של האקדמיה מתאר את הקורסים, המדריכים ומקרי השימוש כחינמיים (Free).
</Callout>

## איך בונים מסלול המשך אחרי הקורס?
בוחרים לפי מה שחסר לך, לא לפי הסדר:

- **רוצה לחזק את היסודות?** עבור על Claude Code 101 במקביל לרמות "מתחיל" ו"מתחיל+" אצלנו. הטבלה למעלה מראה איזה שיעור מקביל לאיזה.
- **עובד כבר יומיומית ורוצה לתת ל-Claude לרוץ לבד?** Claude Code in action, ובעיקר השיעור על אימות ריצות בלי השגחה. אצלנו הנושא מרוכז ב[סעיף האימות בשיעור Routines](/pro/routines#איך-בודקים-עבודה-שרצה-בלי-השגחה).
- **בונה כלים לצוות?** Introduction to agent skills ו-Introduction to subagents, יחד עם שיעורי [Skills](/advanced/skills) ו-[Subagents](/advanced/subagents).
- **רוצה לעבוד נכון עם סוכן, בלי קשר לכלי?** מסלול AI Fluency, שהוא גם השיעור הבא אצלנו.

האקדמיה מתעדכנת, ושמות וקורסים יכולים להשתנות. לפני שממליצים על קורס לצוות, כדאי לפתוח את [עמוד Claude Code](https://academy.claude.com/products/code) ולבדוק מה מופיע בו היום.
