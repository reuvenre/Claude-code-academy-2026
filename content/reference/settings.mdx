כאן תמצא רשימה נבחרת של 60 מפתחות `settings.json` שימושיים ב-Claude Code, מסודרים לפי נושא, ולפניהם תזכורת קצרה: איפה יושב כל קובץ הגדרות ומי גובר כשיש התנגשות. הרשימה המלאה (מאות מפתחות) נמצאת ב[דף הרשמי](https://code.claude.com/docs/en/settings-reference).

## איפה נמצאים קבצי ההגדרות?

| קובץ | היקף | למי זה חל |
| --- | --- | --- |
| `~/.claude/settings.json` | User | לך, בכל פרויקט במחשב הזה. |
| `.claude/settings.json` | Shared project | לכל מי שעובד בתיקייה. ב-git מבצעים לו commit כדי שהצוות יקבל אותו. |
| `.claude/settings.local.json` | Project local | לך, בפרויקט הזה בלבד. Claude Code משאיר אותו מחוץ ל-git כשהוא יוצר אותו. |
| `managed-settings.json` ומקורות managed אחרים | Managed | לכל מי שהארגון פורס אליו; הגדרות שלך לא דורסות אותו, מלבד כמה חריגים אבטחתיים. |

בנוסף, כמה מפתחות נשמרים ב-`~/.claude.json` (global config) ולא בקבצי ההגדרות.

## מי גובר כשאותו מפתח מוגדר בכמה מקומות?

מהגבוה לנמוך:

1. **Managed settings** — מה שהארגון פורס.
2. **ארגומנטים בשורת הפקודה** — דגלים לסשן אחד, כולל `--settings`.
3. **`.claude/settings.local.json`** — הגדרות אישיות לפרויקט.
4. **`.claude/settings.json`** — הגדרות הפרויקט המשותפות.
5. **`~/.claude/settings.json`** — הגדרות המשתמש.

מפתחות מסוג רשימה, כמו `permissions.allow`, מתמזגים בין הקבצים במקום לדרוס זה את זה (עם כמה חריגים, כמו `fallbackModel`). משתני סביבה אינם רמה בסדר הזה; ההכרעה ביניהם לבין מפתח מקביל נעשית לכל זוג בנפרד.

בעמודת "היקף" בטבלאות: **כל קובץ** = user,‏ project,‏ local ו-managed; **Managed** = רק בהגדרות מנוהלות של הארגון.

## הרשאות ו-sandbox

| מפתח | מה הוא עושה | היקף |
| --- | --- | --- |
| `permissions.allow` | מאשר שימושים בכלים שברשימה בלי לשאול. | כל קובץ |
| `permissions.ask` | תמיד שואל לפני שימושים בכלים שברשימה. | כל קובץ |
| `permissions.deny` | חוסם שימושים בכלים שברשימה, כולל קריאה של קבצים עם סודות. | כל קובץ |
| `permissions.additionalDirectories` | נותן ל-Claude גישה לתיקיות מחוץ לתיקייה הנוכחית. | כל קובץ |
| `permissions.defaultMode` | קובע באיזה permission mode סשן חדש מתחיל (`default`,‏ `acceptEdits`,‏ `plan`,‏ `auto`,‏ `dontAsk`,‏ `bypassPermissions`). | כל קובץ |
| `permissions.disableBypassPermissionsMode` | מונע מכל אחד להיכנס למצב `bypassPermissions`. | כל קובץ |
| `disableAutoMode` | מסיר את auto mode ממחזור מצבי ההרשאות. | כל קובץ |
| `allowManagedPermissionRulesOnly` | הופך את ה-managed settings למקור היחיד של כללי הרשאות. | Managed |
| `skipDangerousModePermissionPrompt` | מדלג על חלון האישור לפני כניסה ל-`bypassPermissions`. | User, local או managed |
| `sandbox.enabled` | מפעיל sandbox לפקודות Bash ב-macOS,‏ Linux ו-WSL2. | כל קובץ |
| `sandbox.network.allowedDomains` | מאשר מראש דומיינים כדי שפקודות ב-sandbox לא ישאלו עליהם. | כל קובץ |

כתיבת כללים ומצבי הרשאות מוסברים בשיעור [מצבי הרשאות](/beginner-plus/permission-modes) ובשיעור [הרשאות ו-sandbox](/advanced/permissions-sandbox).
