כאן תמצאו את שמות הכלים המובנים ש-Claude משתמש בהם בסשן, מחולקים לקטגוריות, עם תיאור קצר וסימון אם הכלי מבקש הרשאה. משתמשים בעמוד כשכותבים כללי הרשאות, hooks, `--allowedTools` או רשימת כלים ל-subagent, ששם צריך את השם המדויק.

עמודת **הרשאה** מציינת אם הכלי מבקש אישור במצב Manual עבור נתיבים בתוך תיקיית העבודה. כלים שמסומנים "לא", כמו `Read`,‏ `Grep` ו-`Glob`, עדיין מבקשים אישור לנתיבים מחוץ לתיקיות העבודה. `Bash` מסומן "כן", אבל מריץ סט מובנה של פקודות קריאה-בלבד בלי לשאול. ב-Pro,‏ Max ו-Team הסשן מתחיל ב-auto mode, שבו classifier מחליט על רוב הבקשות. הסבר על המצבים: [מצבי הרשאות](/beginner-plus/permission-modes).

## קבצים וקוד

| כלי | מה הוא עושה | הרשאה |
| :-- | :-- | :-- |
| `Read` | קורא תוכן של קבצים, כולל תמונות, PDF ו-Jupyter notebooks. לא קורא תיקיות. | לא |
| `Edit` | עריכה ממוקדת: מחליף מחרוזת מדויקת (`old_string`) במחרוזת חדשה, בלי regex. | כן |
| `Write` | יוצר קובץ חדש או דורס קובץ קיים עם התוכן המלא. | כן |
| `NotebookEdit` | משנה תא אחד ב-Jupyter notebook (החלפה, הוספה או מחיקה). | כן |
| `Glob` | מוצא קבצים לפי תבנית שם, כמו `**/*.js`. לא קיים כברירת מחדל ב-macOS,‏ Linux ו-WSL. | לא |
| `Grep` | מחפש תבניות בתוך תוכן קבצים (מבוסס ripgrep). לא קיים כברירת מחדל ב-macOS,‏ Linux ו-WSL. | לא |
| `LSP` | אינטליגנציית קוד דרך language server: קפיצה להגדרה, חיפוש הפניות, דיווח על שגיאות טיפוס. פעיל רק אחרי התקנת plugin מתאים. | לא |

## איך מפנים לכלי בכללי הרשאות?

כל המקומות שמקבלים שם כלי משתמשים באותו פורמט: `ToolName(specifier)`. ה-specifier תלוי בכלי:

| פורמט | חל על | התאמה לפי |
| :-- | :-- | :-- |
| `Bash(npm run *)` | Bash,‏ Monitor | תבנית פקודה |
| `PowerShell(Get-ChildItem *)` | PowerShell | תבנית פקודה |
| `Read(~/secrets/**)` | Read,‏ Grep,‏ Glob,‏ LSP | תבנית נתיב |
| `Edit(/src/**)` | Edit,‏ Write,‏ NotebookEdit | תבנית נתיב |
| `Skill(deploy *)` | Skill | שם ה-skill |
| `Agent(Explore)` | Agent | סוג ה-subagent |
| `WebFetch(domain:example.com)` | WebFetch | דומיין |
| `WebSearch` | WebSearch | בלי specifier: מאשרים או חוסמים את הכלי כולו |

כלים שלא מופיעים בטבלה, כמו `ExitPlanMode`, מקבלים רק את השם עצמו. ב-`matcher` של hooks משתמשים בשם הכלי בלבד, בלי סוגריים. פירוט נוסף: [הרשאות ו-sandbox](/advanced/permissions-sandbox).
