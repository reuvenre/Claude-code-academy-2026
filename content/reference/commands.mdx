זו רשימה נבחרת של כ-57 פקודות סלאש מתוך יותר מ-110 שבדף הרשמי, מסודרת לפי שלבי העבודה בסשן. הקלד `/` כדי לראות את הפקודות שזמינות לך. הזמינות תלויה בפלטפורמה, בתוכנית ובסביבה. הרשימה המלאה: [דף Commands הרשמי](https://code.claude.com/docs/en/commands).

כמה כללים שכדאי לזכור:

- פקודה מזוהה רק בתחילת ההודעה; הטקסט שאחריה הופך לארגומנטים שלה.
- בטבלאות, `<arg>` מסמן ארגומנט חובה ו-`[arg]` ארגומנט אופציונלי.
- **Skill** מסמן skill מובנה (bundled skill): פרומפט שנמסר ל-Claude, בדיוק כמו skills שאתה כותב בעצמך. השאר הן פקודות מובנות ב-CLI.

## סשן ראשון בריפו: מה מריצים קודם?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/init` | מאתחל את הפרויקט עם קובץ `CLAUDE.md` מנחה; עם `CLAUDE_CODE_NEW_INIT=1` מתקבל תהליך אינטראקטיבי שעובר גם על skills,‏ hooks וקובצי זיכרון אישיים. |
| `/memory` | עריכת קובצי `CLAUDE.md`, הפעלה או כיבוי של auto memory וצפייה ברשומות שלו. |
| `/mcp [reconnect <server>\|enable\|disable [<server>\|all]]` | ניהול חיבורי שרתי MCP ואימות OAuth; בלי ארגומנט נפתחת רשימה אינטראקטיבית. |
| `/permissions` | ניהול כללי allow,‏ ask ו-deny להרשאות כלים בדיאלוג אינטראקטיבי (כינוי: `/allowed-tools`). |
| `/hooks` | הצגת הגדרות ה-hooks לאירועי כלים. |
| `/skills` | רשימת ה-skills הזמינים, עם סינון לפי שם, תיאור או מקור. |
| `/plugin [subcommand]` | ניהול plugins; בלי ארגומנט נפתח תפריט, או מעבירים תת-פקודה כמו `list`,‏ `install`,‏ `enable` או `disable`. |
| `/add-dir <path>` | הוספת תיקיית עבודה נוספת לגישה לקבצים בסשן הנוכחי. |
| `/agents` | מציג תזכורת לבקש מ-Claude ליצור או לנהל subagents, או לערוך ישירות את `.claude/agents/` או `~/.claude/agents/`. |
| `/terminal-setup` | מתקין קיצור Shift+Enter לשורה חדשה בטרמינלים נתמכים כמו VS Code,‏ Cursor,‏ Alacritty ו-Zed. |
| `/help` | הצגת עזרה והפקודות הזמינות. |

## תוך כדי משימה: איך שולטים במודל ובהקשר?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/plan [description]` | כניסה ל-plan mode ישירות מהפרומפט; אפשר להוסיף תיאור כדי להתחיל מיד במשימה, למשל `/plan fix the auth bug`. |
| `/model [model]` | החלפת מודל ה-AI ושמירתו כברירת מחדל לסשנים חדשים; בלי ארגומנט נפתח בורר (שמות המודלים: [model-config](https://code.claude.com/docs/en/model-config)). |
| `/effort [level\|auto\|status]` | קביעת רמת ה-effort: `low` עד `xhigh`,‏ `max`,‏ `ultracode` או `auto`; `status` מדפיס את הרמה הנוכחית. |
| `/fast [on\|off]` | הפעלה או כיבוי של fast mode. |
| `/context [all]` | הצגת ניצול ההקשר כרשת צבעונית, עם הצעות לאופטימיזציה ואזהרות קיבולת. |
| `/compact [instructions]` | פינוי מקום בהקשר על ידי סיכום השיחה עד כה; אפשר להעביר הנחיות מיקוד לסיכום. |
| `/btw [question]` | שאלת צד על הסשן הנוכחי בלי להוסיף אותה להיסטוריית השיחה. |
| `/goal [condition\|clear]` | הגדרת מטרה: Claude ממשיך לעבוד לאורך תורות עד שהתנאי מתקיים; `clear` מבטל מטרה פעילה. |
| `/copy [N]` | העתקת התשובה האחרונה של Claude ללוח; `N` מעתיק את התשובה ה-N מהסוף. |

## איך מריצים עבודה במקביל?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/tasks` | צפייה וניהול של עבודת רקע בסשן הנוכחי, כולל subagents שסיימו (גם `/bashes`). |
| `/background [prompt]` | מנתק את הסשן הנוכחי כך שירוץ כ-background agent ומשחרר את הטרמינל (כינוי: `/bg`). |
| `/batch <instruction>` | **Skill.** מתזמר שינוי גדול בקוד במקביל: מפרק ל-5 עד 30 יחידות, ואחרי אישור מריץ subagent לכל יחידה ב-git worktree נפרד שפותח pull request. |
| `/fork [prompt]` | מעתיק את השיחה הנוכחית לסשן רקע חדש, ואתה ממשיך לעבוד כאן. |
| `/subtask <task>` | מפעיל subagent ברקע שיורש את כל השיחה; התוצאה שלו חוזרת לשיחה הנוכחית כשהוא מסיים. |
| `/loop [interval] [prompt]` | **Skill.** מריץ פרומפט שוב ושוב כל עוד הסשן פתוח; בלי interval,‏ Claude קובע את הקצב בעצמו (כינוי: `/proactive`). |
| `/schedule [description]` | יצירה, עדכון, הצגה או הרצה של routines שרצות בענן (כינוי: `/routines`). |

## לפני ששולחים: איך בודקים את השינויים?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/diff` | סקירת השינויים בתיקיית העבודה, כולל העריכות ש-Claude עשה עד עכשיו. |
| `/code-review [low\|medium\|high\|xhigh\|max\|ultra] [--fix] [--comment] [pr#\|branch\|path]` | **Skill.** סוקר את ה-diff הנוכחי, או PR,‏ branch או נתיב, לאיתור באגי נכונות; `--fix` מחיל את הממצאים, `--comment` מפרסם אותם ב-PR ב-GitHub או ב-merge request ב-GitLab, ו-`ultra` מריץ סקירה עמוקה בענן (`/ultrareview` הוא כינוי של `/code-review ultra`). כינוי: `/review`. |
| `/review [low\|medium\|high\|xhigh\|max\|ultra] [--fix] [--comment] [pr#\|branch\|path]` | כינוי של `/code-review`, עם אותן רמות ואותם דגלים. |
| `/security-review` | ניתוח השינויים ב-branch הנוכחי מול ה-branch ברירת המחדל של `origin` לאיתור חולשות אבטחה, כמו injection, בעיות אימות וחשיפת מידע. |
| `/simplify [target]` | **Skill.** סוקר את הקוד שהשתנה לאיתור הזדמנויות ניקוי ומחיל את התיקונים; לא מחפש באגי נכונות. |
| `/verify` | **Skill.** מוודא ששינוי עושה את מה שצריך על ידי בנייה, הרצה וצפייה באפליקציה, ולא רק על סמך בדיקות. |
| `/run` | **Skill.** מריץ את האפליקציה של הפרויקט ומתפעל אותה כדי לראות שינוי עובד בפועל. |

## בין סשנים: איך ממשיכים, מפצלים ומעבירים שיחה?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/clear [name]` | פתיחת שיחה חדשה עם הקשר ריק; שם אופציונלי מתייג את השיחה הקודמת בבורר של `/resume` (כינויים: `/reset`,‏ `/new`). |
| `/resume [session]` | חזרה לשיחה לפי מזהה או שם, או פתיחת בורר הסשנים (כינוי: `/continue`). |
| `/branch [name]` | יצירת ענף של השיחה בנקודה הנוכחית כדי לנסות כיוון אחר בלי לאבד את המקור, שאליו חוזרים עם `/resume`. |
| `/rename [name]` | שינוי שם הסשן והצגתו בשורת הפרומפט; בלי שם, נוצר שם אוטומטי מהשיחה. |
| `/export [filename]` | ייצוא השיחה כטקסט רגיל, לקובץ או ללוח. |
| `/teleport` | משיכת סשן ענן לטרמינל הזה, כולל ה-branch והשיחה; דורש מנוי claude.ai (כינוי: `/tp`). |
| `/remote-control` | הופך את הסשן לזמין ל-Remote Control מ-claude.ai (כינוי: `/rc`). |
| `/desktop` | המשך הסשן באפליקציית Claude Code Desktop; דורש macOS או Windows x64 ומנוי Claude (כינוי: `/app`). |
| `/exit` | יציאה מה-CLI; בסשן רקע מחובר, הפקודה מתנתקת והסשן ממשיך לרוץ (כינוי: `/quit`). |

| :--- | :--- |
| `/rewind` | החזרת השיחה ו/או הקוד לנקודה קודמת, או סיכום החל מהודעה שנבחרה (כינויים: `/checkpoint`,‏ `/undo`). |
| `/doctor` | **Skill.** בדיקת התקנה והגדרות שמאבחנת בעיות ויכולה לתקן אותן, כולל התקנות כפולות, בעיות `PATH` וקובצי הגדרות שלא ניתן לפענח; מדווח על הממצאים ומבקש אישור לפני כל שינוי (כינוי: `/checkup`). |
| `/debug [description]` | **Skill.** מפעיל רישום debug לסשן הנוכחי ומאבחן בעיות מתוך הלוג; הרישום נאסף מרגע ההפעלה והלאה. |
| `/status` | פתיחת ממשק ההגדרות בלשונית Status: גרסה, מודל, חשבון וקישוריות; עובד גם בזמן ש-Claude עונה. |
| `/feedback [report]` | שליחת משוב על Claude Code, באותו דיאלוג של `/bug` ועם אותו שלב הסכמה. |
| `/release-notes` | הצגת ה-changelog בבורר גרסאות אינטראקטיבי. |

## חשבון והגדרות: איפה משנים העדפות?

| פקודה | מה היא עושה |
| :--- | :--- |
| `/login` | התחברות לחשבון Anthropic. |
| `/logout` | התנתקות מחשבון Anthropic. |
| `/config [key=value ...]` | פתיחת ממשק ההגדרות (theme, מודל, output style ועוד), או קביעת הגדרה ישירות, למשל `/config theme=dark` (כינוי: `/settings`). |
| `/usage` | הצגת עלות הסשן, מגבלות השימוש של התוכנית וסטטיסטיקות פעילות (כינויים: `/cost`,‏ `/stats`). |
| `/theme` | שינוי ערכת הצבעים, כולל אפשרות `auto` שמתאימה את עצמה לרקע הטרמינל. |
| `/statusline` | הגדרת שורת הסטטוס; מתארים מה רוצים, או מריצים בלי ארגומנטים להגדרה אוטומטית לפי פרומפט ה-shell. |
| `/output-style [style]` | הצגת רשימת ה-output styles או מעבר לאחד מהם, למשל `/output-style concise`. |
| `/sandbox` | הפעלה או כיבוי של sandbox mode; זמין רק בפלטפורמות נתמכות. |
